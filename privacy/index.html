1. INTRODUCTION

This Privacy Policy (“Policy”) describes how Michael Davis (“Developer,” “we,” “us,” or “our”) handles information in connection with the use of the Retirement Countdown mobile application (the “Application”).

By downloading, installing, or using the Application, you acknowledge and agree to the terms of this Policy.

2. DATA COLLECTION PRACTICES

2.1 No Collection of Personal Data

The Application does not collect, store, transmit, process, or share any personal data from users.

Specifically, the Application does not collect:

  • Names
  • Email addresses
  • Telephone numbers
  • Physical addresses
  • Location data
  • Government identifiers
  • Financial account information
  • Contacts
  • Photos or media
  • Device identifiers for tracking
  • Usage analytics data
  • Any other information that identifies or could reasonably identify an individual

The Application does not require account registration.

2.2 User-Provided Information Stored Locally

The Application permits users to input limited information, including:

  • A retirement date
  • Optional display preferences
  • Optional widget configuration settings
  • Optional workday calculation settings

All such information:

  • Is stored exclusively on the user’s device
  • Is not transmitted to the Developer
  • Is not transmitted to any third party
  • Is not stored on external servers
  • Is not accessible by the Developer

The Developer has no ability to remotely access, retrieve, or delete such data.

3. PURPOSE OF PROCESSING

Information entered into the Application is used solely for the following on-device purposes:

  • Calculating time remaining until a user-defined retirement date
  • Displaying date breakdowns (years, months, days)
  • Calculating optional workday totals
  • Displaying information within the Application interface
  • Displaying information through device-supported home screen widgets

No information is used for advertising, behavioral tracking, analytics, profiling, marketing, or automated decision-making.

4. IN-APP PURCHASES (PRO VERSION)

The Application may offer optional paid features (“Pro Version”) via in-app purchase.

All payment transactions are processed exclusively by:

  • Google Play for Android devices
  • Apple App Store for iOS devices

The Developer:

  • Does not collect, process, or store payment card information
  • Does not receive users’ financial account details
  • Does not control payment processing systems

Purchase-related data is handled solely in accordance with the applicable platform provider’s privacy policy and terms of service.

5. THIRD-PARTY SERVICES

The Application does not integrate with:

  • Advertising networks
  • Analytics services
  • Cloud storage providers
  • Social media integrations
  • Tracking technologies
  • External APIs that collect user data

The only third parties involved in the distribution and optional purchase process are the platform operators identified above.

6. WIDGET FUNCTIONALITY

The Application may provide home screen widgets supported by the operating system.

Widgets:

  • Access only locally stored Application data
  • Do not transmit information externally
  • Do not independently collect additional data
  • Operate entirely on the user’s device

Widget functionality does not alter the Application’s data handling practices described in this Policy.

7. DATA SECURITY

Because the Application does not transmit or store data externally, all user-entered information remains under the control of the user on their device.

The Developer does not maintain servers that store user data.

Users are responsible for maintaining the security of their own devices. Deleting the Application may permanently delete all locally stored data.

8. CHILDREN’S PRIVACY

The Application does not knowingly collect personal data from children under the age of 13 (or the minimum age required by applicable jurisdiction). Because no personal data is collected, the Application is designed to comply with applicable children’s privacy laws, including COPPA where applicable.

9. USER RIGHTS

Because the Developer does not collect, process, or store personal data:

  • The Developer cannot provide access to user data
  • The Developer cannot modify user data
  • The Developer cannot delete user data remotely

Users may remove locally stored data at any time by uninstalling the Application.

10. PLATFORM COMPLIANCE

This Policy is intended to comply with disclosure requirements of:

  • Google Play Data Safety policies
  • Apple App Store App Privacy requirements

If future versions of the Application introduce new data practices, this Policy will be updated accordingly prior to release.
